# Mental Model Practice

Use these techniques when the learner's reasoning needs diagnosis or a changed
case can test transfer. Return to the shared learning loop as soon as the gap is clear.

## Locate the mistaken assumption

- Ask for a prediction, distinction, or causal account tied to the learner's task.
  Prefer observable reasoning to confidence ratings or trivia.
- Separate unfamiliar vocabulary from a missing prerequisite, causal link, or
  incorrect boundary assumption. Repair only the dependency blocking understanding.
- Compare the prediction with a trace of entities or state, operations, conditions,
  and outcome. Identify the first point where the model and mechanism diverge.
- For generated code, trace execution order and ask which assumptions make an
  important choice valid. Keep code explanation distinct from certifying the change.

## Change the representation

- Walk one concrete case; connect each important outcome to the mechanism.
- Use a counterexample to expose an overgeneralized rule or an analogy to reveal
  structure. State the analogy's mapping and where it stops working.
- Change the example, representation, or prerequisite after an observed gap.
  Repeating the same explanation more emphatically is not a repair.
- Supply expertise when the learner lacks it. Inquiry should create useful
  reasoning, not force the learner to guess a concealed answer.

## Reconstruct and transfer

- Let the learner explain, predict, distinguish, or solve without copying the answer.
  Match the exercise to intended use, not what is easiest to grade.
- Change surface details, ordering, scale, or a boundary condition while preserving
  the mechanism being tested. Ask for the outcome and the reason.
- Treat recall without application as partial evidence. Record the observed repair
  and remaining gap without extrapolating from one exchange to professional readiness.
- End after the requested explanation or useful learning step. Continue into work
  practice only when applying the concept remains the learner's goal.
