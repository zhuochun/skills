# Tutorials and How-To Guides

Read only the section that matches the selected reader job.

## Tutorial

Use a tutorial when a learner needs a first successful experience.

- Control a bounded learning path from a declared starting state.
- Let the learner act and see a meaningful result early.
- Introduce complexity in a sequence that protects confidence.
- Include every prerequisite needed to repeat the path.
- Test the complete path in supported environments.
- Link to explanation and reference instead of interrupting the lesson.

Complete the tutorial when a representative beginner can reach the promised
result without hidden rescue.

## How-to guide

Use a how-to guide when a competent reader needs to solve one named problem.

- State the goal, assumptions, prerequisites, and expected result.
- Start at the first non-obvious action and end when the goal is achieved.
- Keep steps ordered, concrete, and adaptable to declared variations.
- Include checks and recovery for likely consequential failures.
- Link to background and exhaustive interface detail.

Complete the guide when the target reader can solve the named problem and
recognize success.
